# 🚀 YouTube Auto-Redirect with Auto-Subscribe Popup

Ek lightweight aur fast web page jo social media (Instagram, Twitter, etc.) ke internal browser se users ko direct **YouTube App** par redirect karta hai aur channel ka **Subscribe Confirmation Popup** trigger karta hai.

## ✨ Features
* **Automatic App Link:** Internal browsers me link block hone se bachata hai aur YouTube app kholne ki koshish karta hai.
* **Auto Subscribe Popup:** Link open hote hi user ke samne YouTube channel ko subscribe karne ka prompt dikhta hai (`?sub_confirmation=1`).
* **Fallback Option:** Agar kisi device me auto-redirect block hota hai, toh user manually **"Tap here"** par click kar sakta hai.
* **Fast & Lightweight:** Pure HTML, CSS, aur JavaScript par bana hai, koi external heavy frameworks nahi hain.
* **Dark Theme UI:** Modern aur clean dark UI background.
